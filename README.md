# Todd Fox

I work on AI enablement at PG&E: I write the guides, train the people and build the automations that get Copilot, Power BI and Microsoft Fabric into everyday work. Before that, ten years in finance and FP&A, and before that, navigation electronics on a Navy submarine.

On the side I build market analysis tools in Pine Script and Python.

## Current work

- [powerbi-model-health](https://github.com/tfox72/powerbi-model-health): a read-only health check for Power BI semantic models in Microsoft Fabric. A notebook ranks what to fix; an agent skill explains the results and reviews DAX. Pre-release, not yet run on a live tenant.
- [claude-reviewer-agents](https://github.com/tfox72/claude-reviewer-agents): Claude Code subagents that grade finished work (code, dashboards, spreadsheets, documents) against a fixed standard, plus a fixer that applies the findings.
- [pine-scripts](https://github.com/tfox72/pine-scripts): TradingView indicators in Pine Script v6, each with a write-up of how it works and its limits. Analysis only; no signals, no trade execution.
- [power-bi-lab-semantic-dax-deneb](https://github.com/tfox72/power-bi-lab-semantic-dax-deneb): playbooks, prompts and templates for semantic models, DAX and Deneb visuals.
